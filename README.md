## ⚙️ Alur Pengerjaan (Machine Learning Workflow)

1. **Eksplorasi Data (Exploratory Data Analysis - EDA):**
   * Pemeriksaan struktur data, info tipe data, serta deteksi nilai kosong (*missing values*) dan pencilan (*outliers*).
   * Analisis distribusi data dan korelasinya melalui grafik/chart.
2. **Pra-pemrosesan Data (Data Preprocessing):**
   * Penanganan nilai kosong atau data tidak konsisten.
   * *Feature Encoding* (pengubahan variabel kategorikal menjadi numerik).
   * *Feature Scaling* (Standardization / Normalization jika diperlukan).
3. **Pembentukan & Pelatihan Model:**
   * Pembagian dataset menjadi data latih dan data uji (*Train-Test Split*).
   * Pelatihan beberapa algoritma *Machine Learning*.
4. **Evaluasi Model:**
   * Pengujian performa model menggunakan metrik evaluasi seperti *Accuracy, Precision, Recall, F1-Score*, atau *MSE/RMSE*.
   * Visualisasi *Confusion Matrix* atau grafik hasil prediksi.

## 🚀 Cara Menjalankan Project

Ikuti langkah-langkah di bawah ini untuk menjalankan notebook di komputer kamu:

### 1. Clone Repositori Ini
```bash
git clone https://github.com/USERNAME_KAMU/NAMA_REPO.git
cd NAMA_REPO
```

### 2. Buat Virtual Environment (Opsional)
```bash
python -m venv venv
# Untuk Linux / macOS:
source venv/bin/activate
# Untuk Windows:
venv\Scripts\activate
```

### 3. Install Dependensi
```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 4. Jalankan Jupyter Notebook
```bash
jupyter notebook
```
Buka file `tugas_UTS.ipynb` dan jalankan cell secara berurutan.
